Welcome to the SQL User Guide. SQL is a language for working with relational databases. People use it to store, query, update, and organize structured data, especially in applications that need reliable records, relationships between tables, and flexible reporting.

This section is designed to help you build a solid understanding of SQL, focusing on thinking in queries and working with real schemas without diving into database internals.
