Welcome to the Git & GitHub User Guide. Git is a version control system that helps you track changes to your code, while GitHub is a platform for storing repositories and collaborating with other developers. People use them to save work safely, experiment with changes, share code, and work together on software projects.

This section is a beginner‑friendly crash course that takes you from zero Git knowledge to everyday, confident use of Git and GitHub.
