Welcome to the Machine Learning & AI guides. Machine learning is a way of building software that learns patterns from data instead of following rules you write by hand. People use it to predict prices, flag fraud, recommend products, recognize images, understand text, and much more.

This section starts with the core ideas every model shares, works through the classic algorithms you'll use on tabular data, and then moves into deep learning and neural networks.

:::note
These guides are adapted from notes contributed by [Yonibrese](https://github.com/yonibrese).
:::

:::tip
The examples use Python with `numpy`, `pandas`, `scikit-learn`, and (for deep learning) TensorFlow/Keras or PyTorch. If you're new to Python, start with the [Python guides](/python/guides/) first.
:::
